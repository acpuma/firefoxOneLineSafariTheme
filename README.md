# Firefox OneLine Safari StyleTheme
Firefox One Line Safari style theme 
Created a custom style of FoxOne userChrome.css

Used plugins : 
- Bonjourr new tab
- Adaptive Tab Bar Color
- DarkReader

To apply the them copy files to **chrome** folder under your Firefox Profile folder.
